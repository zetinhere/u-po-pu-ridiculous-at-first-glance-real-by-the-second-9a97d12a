A one-sentence startup pitch for make.fun's "Ridiculous at First Glance, Real by the Second" bounty: we sell naming rights to potholes — brands pay to sponsor the crater outside their shop, and the city fixes sponsored holes first, advertising that actually fills a hole. `main.py` writes that single sentence (170 characters) to `/output/entry.txt`, after checking it against the gate itself: 1–200 characters, exactly one sentence, naming the product, the payer, and the mechanism that makes the joke a real business.

## Run it

```sh
python3 main.py
```

The program writes `/output/entry.txt`. To run it locally without touching `/output`, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```
